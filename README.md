# Северный человек — информационный портал

React + TypeScript + Tailwind CSS, Express, SQLite. Главная, Медиа,
Подразделения, Календарь событий, Медиапространство (Telegram/VK/MAX).
Логотип, стартовый экран загрузки и биография Михаила Маваши с источниками.
Календарь открывает сегодняшний день по Москве и сохраняет отдельную отметку
текущей даты при выборе других дней. Светлая и тёмная темы; админка для фото/видео и событий с черновиками.

## Локально

Требуется Node.js 24.12.0 и npm.

```sh
npm ci
npm run setup:local
npm run dev
```

[Сайт](http://localhost:5173) · [Админка](http://localhost:5173/admin).
Пароль создаётся случайно в `.local-admin-password` (права 0600, Git его
игнорирует). Настройки и bcrypt-хеш в `.env`; эти файлы не публикуются.
`setup:local` не перезаписывает существующий `.env`. Не используйте локальный
пароль на production. Время в редакторе и календаре — Москва.

В редакции откройте «Подразделения», найдите город и сохраните адрес в поле
«Ссылка для перехода». Карточка станет кликабельной. Чтобы отключить переход,
очистите поле и сохраните. По умолчанию ссылки не активированы.
Там же доступны необязательные поля: координатор, контакт для связи, ВК,
MAX, Telegram, электронная почта и сайт. Они сохраняются отдельно от адреса
перехода и сами по себе не включают карточку.

## Проверка

```sh
npm run format:check
npm run check
npm run verify:compile
npm run test:e2e
```

Coverage V8: минимум 90% строк и ветвей отдельно frontend/backend/contracts,
включая неимпортированные файлы. Cypress запускает изолированные API, frontend
и временную SQLite с фиктивными данными, не изменяя локальный контент редакции.
Проверочная компиляция `.preview` не является релизом. `npm run build` используется
в Docker-релизе после валидации версионного тега.

## Доставка изменений

Рабочая ветка → PR в `develop` → PR `develop` → `main`.
Прямые push, force push и удаление main/develop запрещены. Обязателен
`quality-gate` GitHub Actions. CODEOWNERS требует апрув `SosnovichIvan`;
только этот пользователь может обойти ревью при слиянии PR. Обязательные
проверки и необходимость PR обходу не подлежат.

Репозиторий публичный; конфигурация правил в `.github/branch-rules.json`.
Релиз — неизменяемый тег `MAJOR.MINOR.PATCH` на коммите из main.
Реальное размещение требует данных VPS и домена; пока production не развёрнут.

Архив прошедших мероприятий: `content/archive.json`, фотографии — `content/media/`.
При работающем локальном API загрузить подборку в медиатеку:
`npx tsx scripts/import-archive.ts`. Скрипт использует локальный пароль, работает
только с `127.0.0.1:3001`, публикует двенадцать материалов и не дублирует существующие.
Медиатека открывается от ранних записей к новым; есть выбор года и обратного
порядка. В админке дата материала задаётся отдельно от описания.
После импорта записи доступны для редактирования в админке.

Карточки медиатеки открывают страницу `/media/:id` с полным описанием, датой и
источниками. Галерея поддерживает стрелки, миниатюры, Home/End, свайп и
полноэкранный просмотр с закрытием Escape. Автоматического перелистывания нет.
В админке откройте «Медиа» → «Редактировать» → «Фотографии события» для
добавления/удаления снимков. Обложка хранится отдельно, до 30 дополнительных
фотографий на материал. Фотографии черновиков доступны только редакции.
В `content/gallery-sources.json` сохранено происхождение дополнительных снимков.
Повторный локальный импорт сверяет SHA-256 фотографий и не создаёт их дубли.

Вход для редакции открывается кнопкой «Войти» в модальном окне поверх текущей
страницы. Успешная авторизация переводит на `/admin`; прямой гостевой `/admin`
тоже открывает окно входа. Закрыть его можно крестиком, Escape или кликом по фону.
