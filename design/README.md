# Дизайн портала

12 адаптивных HTML-макетов: шесть экранов в светлой и тёмной темах, включая
редакцию. Они сохранены в локальном OpenDesign (ID в opendesign.json) и в Git.
`home-dark.html` — стартовый экран. Темы и переходы между экранами доступны в
самих макетах; формы/календарь статических макетов демонстрируют внешний вид.
Полностью рабочие взаимодействия находятся в приложении на localhost:5173.

Направление: редакционная сетка, графит, хвойный зелёный, светлая бумага,
крупная гротескная типографика; северная SVG-иллюстрация без внешних фотоматериалов.
Шрифт — системный Arial/Helvetica без запроса сторонних ресурсов.

Разметка и Tailwind CSS собираются из одного исходника с приложением.
Найденный dataset-профиль Social Media App с розовым акцентом не соответствовал
задаче. Цвета, типографика и композиция выше — собственные проектные решения.

Адаптация проверяется на 390×844 и 1280×900; дополнительные breakpoint 640,
900, 1150 px. На телефоне навигация раскрывается кнопкой, карточки перестраиваются,
формы сохраняют все действия. Системное reduced-motion отключает переходы.

Состояния: загрузка и отказ API с повтором, пустая медиатека/календарь, поиск без
совпадений, вход и ошибка пароля, сохранение, черновик/публикация, подтверждение
удаления. Проверяются браузерными и компонентными тестами. Скриншоты находятся
в cypress/screenshots после `npm run test:e2e`.

Генерация: `npm run verify:compile && npx tsx scripts/render-design.tsx`.
Макеты не содержат паролей, реальных сессий и тестовых анонсов. События/медиа
в исходном интерфейсе пусты до публикации редакцией.
