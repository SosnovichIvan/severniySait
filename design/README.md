# Дизайн портала

13 HTML-макетов: шесть экранов в светлой и тёмной темах, включая
редакцию, и отдельный экран загрузки с логотипом. Они сохранены в локальном OpenDesign (ID в opendesign.json) и в Git.
`home-dark.html` — стартовый экран. Темы и переходы между экранами доступны в
самих макетах; формы/календарь статических макетов демонстрируют внешний вид.
Полностью рабочие взаимодействия находятся в приложении на localhost:5173.

Направление после доработки: тёплая редакционная композиция, светлая бумага,
мягкий угольный фон и приглушённый шалфейный акцент. Вместо иллюстрации главная
содержит описание деятельности. Логотип сохраняется в обеих темах.
Шрифты — системный Segoe UI/Helvetica Neue для интерфейса и Georgia для
основных заголовков; сторонние шрифты и сетевые запросы не требуются.

Карточки имеют радиусы 18–36 px, кнопки и вкладки — форму капсулы,
поля — радиус 14 px. Тени применяются сдержанно, шапка прозрачная, без рамки и скругления, а активный пункт навигации
отмечается подчёркиванием. Hover/press дают небольшое смещение или
масштабирование; reduced-motion отключает переходы и анимации.

Разметка и Tailwind CSS собираются из одного исходника с приложением.
Dataset-профили Editorial Grid и Nature Distilled подсказали направление;
палитра, сочетание шрифтов и композиция — проектные решения, адаптированные
к существующему содержанию. Это не результат пользовательского исследования.

Адаптация проверяется на 390×844 и 1280×900; дополнительные breakpoint 640,
900, 1150 px. На телефоне навигация раскрывается кнопкой, карточки перестраиваются,
формы сохраняют все действия. Системное reduced-motion отключает переходы.

Состояния: загрузка и отказ API с повтором, пустая медиатека/календарь, поиск без
совпадений, вход и ошибка пароля, сохранение, черновик/публикация, подтверждение
удаления. Проверяются браузерными и компонентными тестами. Скриншоты находятся
в cypress/screenshots после `npm run test:e2e`.

Генерация: `npm run verify:compile && npx tsx scripts/render-design.tsx`.
Макеты не содержат паролей, реальных сессий и тестовых анонсов. На главной добавлена биография основателя с источниками. Календарь открывает
сегодняшний день по Москве, отдельно отмечает его даже при выборе другого дня
и возвращается к нему кнопкой «Сегодня».

Календарь остаётся пустым до публикации анонсов редакцией. В макеты главной
и медиатеки включена подтверждённая подборка прошедших событий из
`content/archive.json`. Реальные записи импортируются в локальную БД через
админский API командой `npx tsx scripts/import-archive.ts`.

Логотип — PNG с официального сайта, соответствующий эмблеме из пользовательского
референса. Исходный файл не перерисовывался; на светлой теме применяется CSS invert.
Экран загрузки loading.html демонстрирует реальный bootstrap до готовности API.

Карточки быстрого перехода «Медиа / Подразделения / Календарь» удалены с главной:
основная навигация остаётся в шапке. Карточка основателя включает квадратный
портрет из официального Telegram-канала, подпись с источником и имя под фото.
На широком экране биография справа, на мобильном — ниже карточки. Портрет
загружается лениво с заданными width/height, без смещения разметки.

Хроника охватывает каждый год с 2022 по 2026, восемь материалов.
На странице «Медиа» по умолчанию порядок хронологический, на главной —
три последних датированных материала. В приложении доступны выбор года и
обратная сортировка, в админке — отдельное необязательное поле даты.
Статические макеты показывают эти контролы; рабочие фильтры находятся в приложении.
Материалы с неизвестной датой остаются в конце, без придуманной даты.

Верхняя строка «Информационный портал / Россия / год» и текстовая подпись
возле логотипа удалены. Футер содержит рабочую навигацию по разделам,
внешние ссылки на площадки и вход в редакцию. Основные ссылки — 16 px,
нижняя строка с годом — 14 px и по центру. На телефоне блоки футера идут
последовательно, ссылки переносятся на новые строки, сохраняя область нажатия.

Под большим заголовком главной используется собственная редакционная фраза:
«Сохранять традиции и помогать друг другу — в этом смысл общего дела».
Она не приписывается основателю или другому автору. Две кнопки под заголовком
удалены; фраза выделена крупной типографикой и тонкой вертикальной линией.
